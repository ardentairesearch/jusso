05 How It Works

ONE API
CALL. FULL
CHAIN.

From agent decision to confirmed onchain transaction with full security, gas management, and auditability built in at every step.

01
Identity
Agent Registers
One CLI command creates the organization and stable agent, generates a local P-256 credential, registers only its public key, and provisions the agent's provider-backed Base account.
Local Public Key · OAuth · DPoP
02
Intent
Agent Submits Intent
The agent calls our REST API with an execution request, a transaction or contract call with an idempotency key. A short-lived proof-bound token identifies the exact organization and agent.
REST API · Policy Grant · Idempotency
03
Construction
Platform Simulates & Prices Execution
Jusso prepares the complete native transaction, simulates every phase, applies agent policy, and quotes native gas plus the platform fee in the configured stablecoin.
Native Transaction · Full Simulation · Stable Fee
04
Submission
Sender & Payer Authorize
Turnkey applies separate sender and infrastructure-payer policies. An expiring execution permit binds the approved payload, account, policy version, chain, and fee before signing.
Turnkey · Execution Permit · Base Native AA
05
Confirmation
Webhook Confirms Execution
Your system receives a HMAC-SHA256 signed webhook confirming the result with the transaction hash. The agent continues its workflow with full cryptographic confidence.
HMAC-SHA256 · Signed Webhook · Exponential Backoff

07 Execution Safety

VERIFY.
THEN
ACT.

Onchain autonomy should not mean blind execution. Jusso builds inspection, simulation, policy-aware sponsorship, and finality tracking into the transaction lifecycle.

01 / PRE-FLIGHT
Full native transaction simulation

Every phase, including the execution-fee transfer, is prepared and simulated before the request can enter the signing queue.

02 / CUSTODY
Policy-backed external custody

Wallet keys remain inside Turnkey. Jusso stores provider references and verifies every returned signature before submission.

03 / GAS
Stable execution fees

Agents pay execution fees in a stablecoin while Jusso's payer sponsors native gas through Base's native payer authorization.

04 / PROTOCOLS
Typed action boundaries

Protocol adapters validate markets, assets, amounts, and relevant risk constraints before constructing contract calls.

05 / DELIVERY
Signed completion events

HMAC-SHA256 signed webhooks deliver verifiable execution outcomes with retry handling for transient delivery failures.

06 / AUDIT
Traceable request lifecycle

Request IDs connect authenticated intent, policy decision, execution permit, signed transaction, and confirmed hash.
